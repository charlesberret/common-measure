# Common Measure

Reference data about how the public web is built, beginning with font and CSS structure observed in [HTTP Archive](https://httparchive.org/) crawls.

Status is pre-release. There is no dataset to download yet.

Common Measure does not own or redistribute the crawl. It publishes derived tables with their methodology and attributes HTTP Archive in every output. HTTP Archive is not a partner or endorser.
