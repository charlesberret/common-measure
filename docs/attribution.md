# Attribution

**Status:** draft boilerplate · revise after an HTTP Archive norms check

## Required on every public Common Measure surface

Every shipped file must satisfy [data/README.md#when-a-file-appears](../data/README.md#when-a-file-appears). In short: name the crawl month and state HA derivation; credit Common Measure packaging, grain, and dictionary; and include the non-endorsement sentence (**HTTP Archive is not a partner or endorser** of Common Measure).

### Boilerplate (unapproved)

> Derived from HTTP Archive public crawl data (July 2026).  
> Aggregates © 2026 Common Measure, [license].  
> HTTP Archive is not a partner or endorser of Common Measure.

Replace the month and license per file. Do not drop the third sentence on a sales page.

## What “derived from” means

Common Measure does not republish HTTP Archive’s raw request logs as a product. It publishes reductions: host-level flags, distributions, joins. Credit is still mandatory. Derivative labor is not a substitute for source credit.

## Fonts

Family names, vendor IDs, and license strings observed in files are **evidence of what was served**. They are not:

- a foundry endorsement of this project
- a license to those fonts
- a statement that Common Measure redistributes type

Do not put a foundry logo on a Common Measure pack without that foundry’s say-so.

## Web Almanac

If you reuse a definition that originated in a Fonts chapter, cite **that chapter** as well as Common Measure. Shared ancestry in extraction SQL is likely; shared branding is not.

Do not describe Common Measure as “the 2026 Web Almanac Fonts chapter” or as an official HA publication.
