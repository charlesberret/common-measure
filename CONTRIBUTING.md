# Contributing

This repository is a **draft public face**, not a software project with a contributor ladder.

## What helps

- Issues that catch overclaim, missing denominators, or broken HA attribution
- Pointers to HTTP Archive citation or licensing language we should follow
- Corrections of fact in the draft dictionary (grain, null behavior, metric names)

## What this is not

- A place to submit crawl data or font files
- A general open-data dump
- A request line for unpaid custom extracts (use email; see [docs/access.md](docs/access.md))

## How

Open a GitHub issue on this repository. For access questions, write [charles@charlesberret.net](mailto:charles@charlesberret.net).

Please do not send secrets, buyer lists, or unpublished extracts in issues.
